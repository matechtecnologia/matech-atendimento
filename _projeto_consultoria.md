## VISAO

Nao e um chatbot. Nao e um questionario. Nao e um guia.

E um CONSULTOR EMPRESARIAL DE VERDADE.

Com acesso total ao negocio do cliente. Capaz de diagnosticar, calcular,
comparar, recomendar e acompanhar — semana a semana.

O cliente sente que esta pagando R$ 3.000/mes por consultor humano.
Mas custa uma fracao disso.

## PRINCIPIO HARD

1. O consultor acessa TODOS os dados do negocio do cliente (com permissao)
2. O consultor USA os dados — nao supoe
3. O consultor CALCULA — nao estima
4. O consultor ACOMPANHA — nao so diagnostica uma vez
5. O consultor INDICA servico M.A Tech quando faz sentido — nunca forca

## INTEGRACOES — A PORTA PRA GESTAO

O cliente conecta as ferramentas dele na Consultoria:

- WhatsApp Business (para consultor ver conversas reais)
- Instagram / Meta Ads (para consultor ver campanhas)
- Google Ads (idem)
- Google Calendar (para agendar reunioes)
- Gmail / Outlook (para consultor ver emails)
- Sistema financeiro / ERP (contas a pagar/receber)
- Planilhas (Excel, Google Sheets)
- CRM atual (se tiver)
- Notion / Trello (processos)

**POR QUE ISSO IMPORTA:**
Quando o cliente conecta as ferramentas, o consultor consegue:
1. Fazer consultoria de verdade (com dados reais)
2. Detectar gargalos ocultos (ex: 30 leads no WhatsApp sem resposta)
3. Sugerir gestao empresarial como proximo passo natural

**A Consultoria e a PORTA DE ENTRADA pra Gestao Empresarial.**
O cliente conecta as ferramentas na Consultoria -> o consultor ve tudo
-> recomenda Gestao -> cliente compra Gestao -> M.A Tech fica com
acesso completo -> upsell pra CRM, Trafego, Automacao.

E uma escada de valor:
  Consultoria (isca)
    -> Gestao (R$ 597)
    -> CRM (R$ 297)
    -> Trafego (R$ 497)
    -> Automacao (R$ 397)

## MODELO DE NEGOCIO

### Fase 1 — AGORA (validacao)
- Foco: conseguir clientes na plataforma
- Consultoria: versao basica, acesso restrito ao admin
- Cliente ve tela "Em Desenvolvimento"
- Preco: incluso no plano (isca)

### Fase 2 — BETA FECHADO (quando tiver 50+ clientes)
- Consultoria liberada pra clientes selecionados
- Acesso completo aos dados
- Preco: R$ 97/mes (add-on)

### Fase 3 — CONSULTORIA HARD (quando tiver 100+ clientes)
- Versao profissional completa
- IA com memoria de longo prazo + acesso total + calculos
- Preco: R$ 297/mes

### Fase 4 — CONSULTORIA SUPREMA (futuro)
- Consultor que negocia, contrata, investe (com aprovacao)
- Preco: R$ 997+/mes
